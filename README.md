# Cat Photo Gallery

A simple, responsive web gallery showcasing delightful cat photographs.

## Overview

This project creates a beautiful, responsive gallery for displaying cat photographs. It features:

- A clean, modern design with hover effects
- Responsive grid layout that adapts to different screen sizes
- Interactive lightbox for viewing enlarged images
- Filter buttons for categorizing images (functionality to be implemented)
- Placeholder images that are replaced with actual cat photos via JavaScript

## Files

- `cat_gallery.html` - The main HTML file containing the gallery structure and styling
- `gallery.js` - JavaScript file that enhances the gallery with interactive features
- `README.md` - This documentation file

## Usage

1. Clone or download this repository
2. Open `cat_gallery.html` in a web browser to view the gallery
3. Click on any image to view it in a lightbox
4. Use the filter buttons at the top to filter images (note: filtering functionality is currently just a placeholder)

## Customization

To use your own cat images:

1. Edit the `catImages` array in `gallery.js` to include URLs to your own images
2. Modify the captions in the HTML file to match your images
3. Adjust the styling in the CSS section as needed
